# PulseVisual - Audio Visualization Mod for Minecraft

🎵 Мод визуализации звука и пульса для Minecraft с красивыми графическими эффектами.

## Особенности

✨ **4 типа визуализации:**
- **Волны** - классическая визуализация звука волнами
- **Пульс** - концентрические круги, пульсирующие под музыку
- **Частицы** - динамические частицы, движущиеся под звук
- **Окружность** - визуализация вокруг центра экрана

🎨 **4 цветовые схемы:**
- Синий
- Красный
- Зелёный
- Радуга (динамическая смена цветов)

🎮 **Интуитивное меню:**
- Переключение эффектов
- Выбор цветов
- Управление громкостью
- Информация о программе

## Установка

### Требования
- Java 8 или выше
- Minecraft 1.16.5+
- Forge для вашей версии Minecraft

### Пошаговая инструкция

1. **Сборка проекта:**
   ```bash
   chmod +x build.sh
   ./build.sh
   ```

2. **Установка мода:**
   - Скопируйте `Jar/PulseVisual.jar` в папку `mods` вашего Minecraft
   - Папка обычно находится в `.minecraft/mods/`

3. **Запуск:**
   - Откройте Minecraft Launcher
   - Выберите профиль с Forge
   - Нажмите Play
   - Мод будет автоматически загружен

## Использование

1. Запустите PulseVisual из главного меню Minecraft или запустите JAR напрямую
2. Используйте меню для переключения визуализации:
   - **Эффекты** → Выберите тип визуализации
   - **Цвета** → Выберите цветовую схему
   - **Громкость** → Управляйте интенсивностью
